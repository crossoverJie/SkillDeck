Changelog

Every version, every fix, every feature. SkillDeck follows semantic versioning — patch for fixes, minor for new agents and capabilities.

v0.1.2

Oct 26, 2026
  1. Feat One-click batch updates: update every skill with a pending update from the sidebar toolbar, with live progress. Skills from the same repository share a single clone, files are staged and swapped atomically with rollback, and interrupted updates are recovered on the next launch. #69
  2. Fix Update toolbar states: check and update actions are disabled while a conflicting operation is running, and update errors now follow the app language. #69

v0.1.1

Oct 23, 2026
  1. Feat Dashboard usage refresh: usage counts can now be refreshed from the dashboard toolbar, with throttled auto-refresh when the window becomes active. Previous counts stay visible while scanning, and a failed refresh keeps the last readable snapshot marked as stale. #70

v0.1.0

Oct 22, 2026
  1. Feat Skill usage statistics: added a unified usage view that aggregates invocation history across all supported agents. #64
  2. Feat Claude Code usage stats: added skill usage history scanning for Claude Code sessions. #66
  3. Feat Copilot CLI usage stats: added skill usage history scanning for Copilot CLI sessions. #67
  4. Feat Dashboard usage sorting: skills can now be sorted by usage in the dashboard. #68
  5. Feat Agent brand icons: added bundled brand icons for agents and the sidebar. #65
