Changelog

Every version, every fix, every feature. SkillDeck follows semantic versioning — patch for fixes, minor for new agents and capabilities.

v0.2.0

Nov 14, 2026
  1. Feat Dashboard grouped by source repository: the skill list is now segmented by where each skill was installed from, so skills belonging to the same repo always sit together — the two obra/superpowers skills, the five anthropics/skills ones, and so on. Grouping is orthogonal to sorting: the existing Name / Scope / Agent Count / Usage Count orders still decide the order inside a section and the order of the sections themselves. Repo names that differ only in casing merge into one section with a deterministic header, local installs show their folder name, and skills with no recorded source fall into a single “Local / No Source” bucket. No lock file or filesystem change: the group key comes from the entry SkillDeck already had in memory. #75
  2. Feat Collapsible sections with a source link: clicking a section header folds or unfolds that repository's skills, and GitHub-backed groups get a button that opens the repository in your browser. Header state is keyed by the source, so it survives sorting, filtering and refreshes. A “Group By” menu switches back to the old flat list at any time. #75
  3. Fix Skill list width and sidebar toolbar: the middle column was capped at 450pt, and the sidebar's four toolbar icons needed more room than the column could ever offer, so “Refresh skills” was permanently exiled into the overflow menu. The middle column now grows to 720pt, and the sidebar's update actions collapsed into one split button — refresh stays a single click, check-for-updates and update-all moved into its menu. Long skill names are truncated to one line with a hover tooltip, and the agent icon cluster caps at five icons plus a “+N” counter, so the name no longer wraps. #74
  4. Feat Localized sort and group menus: the dashboard's sort menu and its toolbar button followed neither language setting — both stayed hard-coded English. Sort labels, the new grouping labels and section headers now follow the app language in English and Simplified Chinese. #75

v0.1.5

Nov 9, 2026
  1. Feat Global skill disable / enable: A/B-testing two similar skills now takes a single switch. SkillDeck renames the one canonical SKILL.md to a hidden .SKILL.md.disabled marker, which hides that skill from all 15 agents at once — including Codex, OpenCode, Qoder and Pi, which read ~/.agents/skills/ natively and have no symlink to remove. No symlink and no .skill-lock.json entry are touched, so every assignment is preserved and re-enabling restores the skill with no snapshot. The state is derived from the filesystem on every scan, so it survives restarts. #73
  2. Feat Disabled state in the dashboard: a disabled skill stays in the list, greyed out with a “Disabled” badge, instead of disappearing. Its per-agent switches, editor, update actions and repository linking are frozen until it is re-enabled, and the detail page gains an availability switch plus a Cmd+Shift+D shortcut for fast toggling. #73
  3. Feat Broken skill recovery: if the hidden marker is deleted by hand or by another tool, the skill no longer silently vanishes. It stays visible as a “SKILL.md Missing” row offering Delete or Reinstall, the latter rebuilding SKILL.md from the linked GitHub repository. #73

v0.1.4

Nov 8, 2026
  1. Fix OpenCode usage counts: OpenCode keeps its history in a WAL-mode SQLite database, and once the app closes, a read-only connection can no longer rebuild the -shm index it needs. The scan failed against that database, so OpenCode usage stayed empty and every skill carried a “usage may be incomplete” warning. SkillDeck now verifies the connection with a cheap read and retries with a read-write handle when needed, so OpenCode counts — and the warning badge — are correct again. #72

v0.1.3

Nov 7, 2026
  1. Feat Pi support: added Pi as the 15th supported agent. Pi reads the Agent Skills location ~/.agents/skills/ natively, so managed skills show as native support instead of needing a per-agent symlink. #71
  2. Feat Pi usage statistics: Pi skill activations now appear in the dashboard usage column. Pi pastes a skill's SKILL.md straight into the conversation instead of loading it with a tool call, so both activation paths are counted. #71
  3. Feat Agent order: the sidebar and every agent picker now list daily-driver agents first, with Gemini CLI, Antigravity and OpenClaw moved to the bottom. #71
  4. Fix Native support detection: skills in ~/.agents/skills/ are recognized as native support even when that directory did not exist yet at launch, instead of being shown as inherited from another agent. #71
